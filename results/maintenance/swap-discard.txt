## First test on stb2, by hand (my mistake included)
swapoff LV; blkdiscard LV -> "Discarded 3758096384 bytes"; swapon -> "read swap header failed"
  (blkdiscard wiped the swap header) -> mkswap /dev/mapper/ol-swap; swapon --discard=once -> swap back, 5 GB
image 21700 MB -> 16680 MB, host free 3586 MB -> 8606 MB
then ~10 min running (CRS + standby) and a shutdown: image back to 17.8 GB (+1.1 GB) -> one-off discard is not
enough, the swap entries need "discard"
